# AI Code Reviewer Documentation

This folder contains the initial planning documents for the AI Code Reviewer app.

## Documents

- [Project Brief](./project-brief.md): product goal, scope, and user flow.
- [Architecture Plan](./architecture-plan.md): folder responsibilities and module boundaries.
- [API Plan](./api-plan.md): first review endpoint contract and server-side flow.
- [Component Plan](./component-plan.md): reusable UI and feature components.
- [Development Phases](./development-phases.md): beginner-friendly implementation roadmap.

## Guiding Principles

- Use Next.js App Router.
- Keep UI components reusable and small.
- Keep OpenAI calls on the server.
- Use TypeScript for shared contracts.
- Prefer server components unless client interactivity is required.
- Build a responsive, dark, developer-focused interface.
